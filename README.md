# HashVeil

Windows 10/11 媒体文件哈希扰动工具。批量为视频和图片添加不可见随机标记，改变 SHA-256/MD5 等文件哈希，不解码、不转码，不影响画面和音频内容。

## 使用

1. 从 Releases 下载 `HashVeil.exe`，双击运行，无需安装 Python 或 FFmpeg。
2. 选择包含媒体文件的源文件夹。
3. 保持默认的“输出到新文件夹”，点击“扫描媒体”和“开始处理”。
4. 上传输出目录中的文件。

工具会递归保留目录结构。重复处理会替换旧标记，不会持续增大文件。默认生成副本；“直接修改原文件”模式请先备份。

> 注意：工具改变的是文件哈希，不提供加密或访问控制。部分网盘可能使用内容识别而不是整文件哈希，此工具不保证绕过任何平台审核，请遵守平台规则和适用法律。

## 开发与测试

```powershell
python -m unittest discover -s tests -v
.\build.ps1
```

## 原理

在文件末尾写入带版本标识的 32 字节密码学随机值。主流媒体解码器会忽略媒体逻辑结束位置之后的数据，因此无需重新编码，处理速度主要受磁盘读写速度限制。输出模式采用临时文件和原子替换，取消或异常时不会留下半成品。
